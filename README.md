# 🎯 Kaggle & Data Science Portfolio

ยินดีต้อนรับสู่คลังสะสมผลงานการฝึกฝนและทดลองแก้ปัญหาด้าน **Data Science**, **Machine Learning**, และ **Deep Learning** จากชุดข้อมูลและการแข่งขันบน [Kaggle](https://www.kaggle.com/)

---

## 📌 สรุปจุดประสงค์ (Overview & Goal)

โปรเจกต์ในคลังนี้จัดทำขึ้นเพื่อมุ่งเน้นการลงมือปฏิบัติจริง (**Hands-on Practice**) และเก็บสะสมผลงาน (Portfolio) โดยครอบคลุมตั้งแต่:
- **Exploratory Data Analysis (EDA)**: การวิเคราะห์สำรวจข้อมูลและสร้างข้อมูลภาพ (Data Visualization) ที่สวยงามและสื่อความหมายด้วย **Seaborn** และ **Matplotlib**
- **Data Preprocessing & Feature Engineering**: การทำความสะอาดข้อมูล การแปลงตัวแปร (Encoding) และการปรับสเกล (Scaling)
- **Machine Learning Modeling**: การฝึกสอนและประเมินผลโมเดลประเภท Classification และ Regression
- **Deep Learning & LLMs**: การทดลองปรับแต่งและสร้างโมเดลภาษาขนาดใหญ่ (Fine-tuning Large Language Models)

## 🎯 แนวทางการพัฒนาทักษะ (Skill Roadmap)

1. 🔍 **EDA & Visualization**: พัฒนาการเล่าเรื่องด้วยข้อมูล (Data Storytelling) ผ่านกราฟวิเคราะห์ที่อ่านง่าย เข้าใจได้ทันที
2. ⚙️ **Preprocessing Standards**: ใช้เทคนิคการเตรียมข้อมูลมาตรฐาน ป้องกัน Data Leakage และจัดการกับปัญหากลุ่มข้อมูลไม่สมดุล (Imbalanced Data)
3. 📈 **Model Optimization**: ฝึกการปรับจูนไฮเปอร์พารามิเตอร์ (Hyperparameter Tuning) และการเลือก Evaluation Metrics ให้ตรงโจทย์ธุรกิจ
4. 🚀 **Portfolio & Documentation**: สรุปบทเรียน ข้อค้นพบ และแนวทางการนำไปใช้งานจริงไว้ในเอกสาร Readme อย่างมืออาชีพ
